# 抖音主页作品下载功能集成

## Context

用户需要在 FiveDesigner 里复刻 `D:\trae_projects\doubao\douyin-downloader` 的核心能力:输入抖音主页 URL,下载该账号的全部图集+视频,保存到当前项目工作目录,并自动写入素材库([MediaAssetManage](file:///d:/trae_projects/fivedesigner/src/pages/MediaAssetManage.tsx)),分类归到"抖音主页"。用户的抖音 Cookie 用 SecureStore 加密自动保存(粘贴一次,后续自动复用)。

## 核心模块设计

### 1. douyinSigner(Worker 签名)

`douyinSigner.worker.ts` 严格 ES5(禁 `?.`/`??`/模板字符串/`class`/`=>`/`import`,仅 `var`/`function`/`let`/`const`):
```js
import aBogusCode from '../a_bogus.js?raw'  // vite ?raw 唯一例外
var generateFn = null
try { (0, eval)(aBogusCode); generateFn = generate_a_bogus } catch (e) { self.postMessage({type:'init-error', error:String(e)}) }
self.onmessage = function (e) {
  var m = e.data; if (m.type !== 'sign') return
  try { self.postMessage({type:'result', id:m.id, success:true, data:generateFn(m.query, m.userAgent)}) }
  catch (err) { self.postMessage({type:'result', id:m.id, success:false, error:String(err)}) }
}
```

`douyinSigner.ts`(主线程 ES6):单例,懒加载 `new Worker(new URL('./douyinSigner.worker.ts', import.meta.url))`,`sign()` 返回 Promise,10s 超时,用 seq id 匹配响应。参考 [vendorSandbox.ts:13](file:///d:/trae_projects/fivedesigner/src/services/vendor/vendorSandbox.ts#L13) 的 Worker 创建模式。

### 2. douyinService

```ts
export interface DouyinWorkItem {
  awemeId: string; type: 'image' | 'video'; desc: string; createTime: number
  authorUid: string; authorNickname: string
  images?: { url: string; width: number; height: number }[]
  videoUrl?: string; coverUrl?: string
}
export function extractSecUserId(homeUrl: string): string  // /user\/(MS4w[^/?#]+)/
export function generateFakeMsToken(): string  // 107 位随机 [0-9a-zA-Z]
export async function fetchDouyinWorks(secUserId, cookie, onProgress?): Promise<{items, hasMore, maxCursor, nickname}>
export async function downloadDouyinFile(url, {projectId, fileName, cookie, mediaType, taskId}): Promise<string>
```

- `fetchDouyinWorks`:循环分页。构造固定设备参数(device_platform=webapp, aid=6383, version_code=170400 等)+ msToken(fake)→ 拼 query 串 → `douyinSigner.sign(query, UA)` 生成 a_bogus → `invoke('http_request', {request:{url:LIST_API+'?'+query+'&a_bogus=...', method:'GET', headers:{'User-Agent':UA,'Referer':'https://www.douyin.com/','Cookie':cookie}, timeout:30000}})` → 解析 aweme_list。每页间隔 800ms~1.5s 随机,最多 20 页/1000 条。参考 [acquire.py](file:///D:/trae_projects/doubao/douyin-downloader/src/download/acquire.py) 的参数和 [parse.py](file:///D:/trae_projects/doubao/douyin-downloader/src/download/parse.py) 的解析规则。
- `downloadDouyinFile`:统一走 `download_video` 命令(流式+进度),传 `media_type` 区分目录。图集逐张调,视频调一次。
- UA 固定:`Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/123.0.0.0 Safari/537.36`(与 a_bogus.js 注释里的 UA 一致)

## 数据流

1. 用户粘贴 URL → `extractSecUserId` 提取 `MS4w...`
2. `useDouyinWorksQuery` → `fetchDouyinWorks` 分页拉取(每页签名)→ items 缓存到 React Query
3. 用户勾选 + 确认当前项目 → `useDownloadDouyinWorksMutation`
4. 逐项:`downloadDouyinFile`(流式,Cookie+Referer)→ 绝对路径
5. `mediaAssetDB.create({category:'抖音主页', tags:[nickname,类型], project_id, ...})`
6. invalidate `mediaAssetKeys.all` → MediaAssetManage 自动刷新,"抖音主页"分类出现

## 错误处理与边界

- **签名失败**:Worker 返回 success:false 或 10s 超时 → toast"签名失败",中止,提供"重试"
- **Cookie 失效**:API status_code≠0 或 aweme_list 空且 has_more=1 → 提示"Cookie 可能失效",弹 Cookie 窗
- **限流**:分页随机间隔 800ms~1.5s;遇异常退避重试 1 次
- **下载失败**:单文件失败不中断整体,记日志标红,继续下一项,最终汇总"成功 X/失败 Y"
- **重复下载**:下载前按 awemeId+idx 查同 project 的 mediaAsset,已存在则跳过(UI 提示)
- **私密账号/空作品**:列表空时显示"未获取到公开作品"
