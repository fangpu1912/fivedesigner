# 衣橱图生图换装弹窗

## Context

当前 [CharacterWardrobeDialog.tsx](file:///d:/trae_projects/fivedesigner/src/components/asset/CharacterWardrobeDialog.tsx) 已有完整衣橱管理 UI（增删改、设默认、图片上传），但**只能手动上传图片**。用户希望在衣橱列表项悬浮按钮里加一个「AI 生图」入口，基于角色主图 + 该服装的 prompt 直接图生图换装换状态，生成的新图应用回该服装的 `image` 字段。

下游联动（`ReferenceImageInput` 已支持角色 outfit 下拉选择）已经齐备，所以本次只补齐衣橱面板自身的「AI 换装」入口即可形成完整闭环。

## 改动范围

只动 2 个文件，新增 1 个文件。**不动** AssetManagerPanel、不动 vimax、不动 characterExtractorAgent。

### 1. 新建 `src/components/asset/OutfitGenerationDialog.tsx`

弹窗职责：基于角色主图 + 服装 prompt 调用图生图，生成新图预览，用户确认后写回 outfit.image。

**Props**：
```ts
interface OutfitGenerationDialogProps {
  open: boolean
  onOpenChange: (open: boolean) => void
  characterId: string      // 通过 useCharacter(characterId) 内部查角色主图
  outfit: CharacterOutfit | null  // null 时不渲染
  projectId?: string
  episodeId?: string
}
```

**布局**（参考现有 [AIImageEditDialog.tsx](file:///d:/trae_projects/fivedesigner/src/components/ai/AIImageEditDialog.tsx) 的弹窗模式）：
- 左侧：角色主图预览（来自 `useCharacter(characterId).data?.image`），下方提示"作为图生图参考图"
- 右侧：
  - 服装名称（只读展示）
  - 生图提示词 `Textarea`（初始值 `outfit.prompt`，可编辑）— 此 prompt 作为 `generateImageToImage` 的 prompt
  - 模型选择器：复用 [VendorModelSelector](file:///d:/trae_projects/fivedesigner/src/components/ai/VendorModelSelector.tsx) `type="image"`
  - 「生成」按钮 → 调用 `useGeneration().generateImageToImage(prompt, characterImage, model, { projectId, episodeId })`
  - 生成进度条（复用 `useGeneration().progress`）
- 生成结果预览区：
  - 显示生成的新图
  - 「重新生成」按钮 / 「应用为服装图片」按钮
  - 应用时：
    1. `saveGeneratedImage(generatedUrl, projectId, episodeId)` 保存到项目目录
    2. `useOutfitMutations().updateAsync({ id: outfit.id, data: { image: savedPath } })` 写回 DB
    3. toast 成功 → 关闭弹窗（React Query 会自动 invalidate，列表自动刷新）

**复用函数**：
- `useGeneration().generateImageToImage(prompt, imageUrl, model, options)` — [useGeneration.ts:87](file:///d:/trae_projects/fivedesigner/src/plugins/storyboard-copilot/hooks/useGeneration.ts#L87)
- `useCharacter(characterId)` — [useCharacters.ts:52](file:///d:/trae_projects/fivedesigner/src/hooks/useCharacters.ts#L52)
- `useOutfitMutations().updateAsync` — [useOutfits.ts:44](file:///d:/trae_projects/fivedesigner/src/hooks/useOutfits.ts#L44)
- `saveGeneratedImage(url, projectId, episodeId)` from `@/utils/mediaStorage`
- `getImageUrl(path)` from `@/utils/asset`
- `VendorModelSelector` from `@/components/ai/VendorModelSelector`
- `useUIStore` 拿 `currentProjectId` / `currentEpisodeId` 兜底（当 props 没传时）

**边界处理**：
- 角色没有主图（`character.image` 为空）→ 显示提示"请先在资产管理中为角色上传主图作为参考"，禁用生成按钮
- 没有可用图片模型 → VendorModelSelector 选项为空时禁用生成按钮
- 生成失败 → toast 提示，停留在弹窗，可重试

### 2. 修改 `src/components/asset/CharacterWardrobeDialog.tsx`

**新增**：
- import `OutfitGenerationDialog`、`Wand2` 图标
- 新增 state：`const [generatingOutfit, setGeneratingOutfit] = useState<CharacterOutfit | null>(null)`
- 在 outfits 列表项的悬浮按钮组（`absolute inset-0 ... group-hover:opacity-100`）里，**在「编辑」按钮前**插入一个「AI 生图」按钮（`<Wand2 className="h-3 w-3" />`），`onClick={(e) => { e.stopPropagation(); setGeneratingOutfit(outfit) }}`
- 在 Dialog 末尾（`</Dialog>` 前）渲染：
  ```tsx
  <OutfitGenerationDialog
    open={!!generatingOutfit}
    onOpenChange={(v) => !v && setGeneratingOutfit(null)}
    characterId={characterId}
    outfit={generatingOutfit}
    projectId={projectId}
    episodeId={episodeId}
  />
  ```
- 注意：`OutfitGenerationDialog` 需要在 `Dialog` 外层（或独立渲染），避免嵌套 Dialog 的层级问题 — 实际放在 CharacterWardrobeDialog 组件 return 的最外层 `<Dialog>` 之外即可（用 React Fragment 包裹）

**新增 prop（可选）**：`onOutfitImageChange?: (outfitId: string, newImagePath: string) => void` — 留给将来 AssetManagerPanel 联动，本次不必接。

## 验证步骤

1. **类型检查**：`npm run typecheck` 0 错误
2. **端到端验证**：
   - 启动 dev：`npm run tauri:dev`
   - 进入"资产管理"页面 → 选择一个有主图的角色 → 点"管理衣橱"
   - 衣橱里至少有 1 套服装（带 prompt）
   - 悬浮到服装卡片 → 出现「AI 生图」按钮（魔棒图标）→ 点击
   - 弹窗显示角色主图 + 服装 prompt（可编辑）+ 模型选择器
   - 选模型 → 点「生成」→ 进度条推进 → 生成结果预览
   - 点「应用为服装图片」→ 衣橱列表中该卡片的图片刷新为新图
3. **边界验证**：
   - 角色无主图时点「AI 生图」→ 显示提示，禁用生成按钮
   - 生成失败 → toast 报错，可重试
4. **下游联动验证**（确认现有功能未受影响）：
   - 在使用 `ReferenceImageInput` 的生图面板里选择该角色 → 下拉切到刚换装的 outfit → 应该看到新图作为参考图
